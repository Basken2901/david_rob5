# Project collaboration rules

## Before editing

- Ask the user for confirmation before modifying any project file.
- Treat existing code and changes as belonging to the user.
- Do not overwrite, remove, or substantially rewrite existing code without explicit permission.
- Additions are allowed after the user approves the requested work; modifications or deletions require explicit permission.

## After editing

- Always report where changes were made.
- Include clickable file paths and relevant line numbers where possible.
- Summarize the changes in each modified file.
- State which files were intentionally left unchanged.
- Report build, test, or validation results, including any tooling limitations or failures.

## State-management work

- Keep joint-state storage and locking in the existing state-manager files.
- Do not create a separate state-manager file unless the user explicitly requests it.
